== Add NuGet package

All libraries that are part of the `PPWCode.Vernacular.NHibernate.III` project are published on NuGet. 

The following packages are available:

- {nuget-main}[{main}], base library
- {nuget-castle}[{castle}], Castle Windsor facility
- {nuget-sql}[{sql}], support for Microsoft SQL Server
- {nuget-pgsql}[{pgsql}], support for PostgreSQL
- {nuget-firebird}[{firebird}], support for Firebird
- {nuget-test}[{test}], support for NUnit integration tests with SQL Server


You can use your IDE to add the required libraries as dependencies to your project, or manually add them in the `.csproj` file.  This would look similar to the following:

[source,xml]
----
include::example$project.csproj[]
----
