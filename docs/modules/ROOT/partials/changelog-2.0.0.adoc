=== Changes

* Property selectors in `PpwAuxiliaryDatabaseObject`, `PpwAuxiliaryIndex<TEntity>`, and
  `UniqueConstraintsForNullableColumn<TEntity>` now accept expressions that select nullable
  properties without requiring the null-forgiving operator (`!`).
* When upgrading, use `object?` as the result type in explicitly typed selector expressions
  and in overrides of `GetColumns`, `GetColumnNames`, or `GetPropertyInfo`. Existing
  declarations that use `object` can produce nullable warnings and fail builds that
  treat those warnings as errors.

=== Dependency updates

The NuGet lock-file refresh includes these dependency updates for the published packages.

* Updated NHibernate to `5.7.1` and `PPWCode.Vernacular.Contracts.I` to `1.6.0`.
* Updated the SQL Server provider dependency `Microsoft.Data.SqlClient` to `7.1.2`
  and the PostgreSQL provider dependency `Npgsql` to `10.0.4`.
* Updated `NHibernate.Extensions.Logging` to `4.0.2` and
  `PPWCode.Util.Time.I` to `2.1.0` in the DI and test support packages.
* Updated Moq to `4.21.0` in the test support package.
* Updated several `Microsoft.Extensions` dependencies and
  `System.Configuration.ConfigurationManager` to `9.0.23` for .NET 9 and
  `10.0.15` for .NET 10.
